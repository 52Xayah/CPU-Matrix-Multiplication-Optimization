# 03. SIMD Optimization: AVX

## 1. 实验目的

在矩阵分块优化的基础上，引入 AVX SIMD 指令，提高单条指令的数据处理能力，研究向量化计算对矩阵乘法性能的影响。

## 2. 实验原理

SIMD（Single Instruction Multiple Data）是一种数据级并行技术。

本实验使用 AVX 256-bit 指令集，每个向量寄存器能够同时容纳 8 个单精度浮点数。

通过向量加载、广播、乘法、加法和存储操作，实现多个浮点数的并行计算。

## 3. 核心指令

| 指令 | 功能 |
|---|---|
| _mm256_set1_ps | 广播单个浮点数 |
| _mm256_loadu_ps | 加载8个浮点数 |
| _mm256_mul_ps | 8路浮点乘法 |
| _mm256_add_ps | 8路浮点加法 |
| _mm256_storeu_ps | 存储8个浮点数 |

对于不足8个元素的剩余部分，使用标量循环处理。

## 4. 实验实现

实验基于 matrix_avx.c 实现。

主要优化过程：

1. 使用 AVX 向量寄存器保存广播后的数据。
2. 一次加载8个连续浮点数。
3. 使用向量乘法和加法完成批量计算。
4. 将计算结果写回矩阵 C。
5. 对无法组成完整8元素向量的部分使用标量处理。

该实现同时结合矩阵分块和 OpenMP 多线程并行。

## 5. 历史实验结果

| SIMD 实现 | 执行时间(s) | 加速比 |
|---|---:|---:|
| 不使用 AVX | 25.928071 | 1.00 |
| 使用 AVX | 20.161636 | 1.29 |

数据来源：原始实验报告，表 2-4。

## 6. 实验结果分析

引入 AVX 后，执行时间由 25.928071 秒下降至 20.161636 秒。

加速比达到约 1.29 倍，执行时间减少约 22.24%。

说明 SIMD 向量化能够提高矩阵乘法的数据级并行能力。

但理论上一次处理8个浮点数，并不意味着整体程序能够获得8倍加速。实际性能还受到数据加载、存储、缓存访问、循环控制和线程调度等因素影响。

## 7. 实验结论

AVX SIMD 指令能够有效提高矩阵乘法的计算效率。

本次历史实验中，AVX 版本相对于不使用 AVX 的对照版本获得约1.29倍加速。

这说明在 Cache Blocking 的基础上引入数据级并行，能够进一步改善矩阵乘法性能。

## 8. 后续研究问题

1. 为什么 AVX 理论上的8路计算能力没有转化为8倍整体加速？
2. 数据加载和存储是否成为新的性能瓶颈？
3. 不同矩阵规模下，SIMD 优化效果是否一致？
4. AVX 与 OpenMP 如何协同工作？
