# 05. Performance Comparison

## 1. 实验目的

综合比较不同矩阵乘法优化策略的性能，分析 Cache Blocking、SIMD 和多线程并行技术对矩阵乘法执行效率的影响。

## 2. 对比实现

本实验比较四种实现策略：

1. Serial：原始串行矩阵乘法。
2. Blocked：矩阵分块优化。
3. Blocked + AVX：矩阵分块与 AVX 向量化。
4. Blocked + AVX + OpenMP：矩阵分块、AVX 和多线程并行的组合优化。

## 3. 实验参数

- 矩阵规模：N = 8192
- 数据类型：float
- 性能指标：执行时间、加速比、GFLOPS

## 4. 历史实验结果

| 实现策略 | 执行时间(s) | 加速比 | GFLOPS |
|---|---:|---:|---:|
| Serial | 5510.266554 | 1.00 | 0.20 |
| Blocked | 260.358425 | 21.16 | 4.22 |
| Blocked + AVX | 202.617213 | 27.20 | 5.43 |
| Blocked + AVX + OpenMP | 20.161636 | 273.30 | 54.53 |

数据来源：原始实验报告，表 2-5。

## 5. 性能指标

理论浮点运算量：

FLOPs = 2N³

计算性能：

GFLOPS = 2N³ / (Time × 10⁹)

加速比：

Speedup = T_serial / T_optimized

## 6. 实验结果分析

根据表 2-5，串行版本的性能为 0.20 GFLOPS。

引入矩阵分块后，性能提高至 4.22 GFLOPS，加速比达到 21.16。

在分块基础上增加 AVX 向量化后，性能达到 5.43 GFLOPS，加速比达到 27.20。

进一步结合多线程并行，最终性能达到 54.53 GFLOPS，相对于串行版本加速273.30倍。

这表明存储层次优化、数据级并行和线程级并行的组合具有显著的性能优势。

## 7. 综合结论

本实验展示了矩阵乘法从基础串行实现到多层次并行优化的性能提升过程。

- Cache Blocking：改善数据局部性，提高缓存利用率。
- AVX SIMD：提高单条指令的数据处理能力。
- OpenMP：利用多核处理器资源，实现线程级并行。

三种技术分别针对不同层面的性能瓶颈，组合使用能够显著提高矩阵乘法的计算效率。
