# 06. Strassen Matrix Multiplication

## 1. 实验目的

学习 Strassen 矩阵乘法算法，理解其通过减少子矩阵乘法次数降低时间复杂度的基本思想。

本章节重点分析算法结构、中间乘积构造方式以及时间复杂度推导。

## 2. 算法基本思想

Strassen 算法通过将矩阵划分为四个子矩阵，构造七个中间乘积，以减少传统分治矩阵乘法所需的乘法次数。

将矩阵 A、B 划分为：

A = [[A11, A12], [A21, A22]]

B = [[B11, B12], [B21, B22]]

## 3. 七个中间乘积

P1 = (A11 + A22)(B11 + B22)

P2 = (A21 + A22)B11

P3 = A11(B12 - B22)

P4 = A22(B21 - B11)

P5 = (A11 + A12)B22

P6 = (A21 - A11)(B11 + B12)

P7 = (A12 - A22)(B21 + B22)

## 4. 结果子矩阵计算

C11 = P1 + P4 - P5 + P7

C12 = P3 + P5

C21 = P2 + P4

C22 = P1 + P3 - P2 + P6

最终将四个子矩阵组合，得到矩阵 C。

## 5. 时间复杂度分析

### 5.1 传统分治矩阵乘法

传统分治方法需要进行8次子矩阵乘法，同时执行矩阵加减操作。

递推关系：

T(N) = 8T(N/2) + O(N²)

根据主定理：

T(N) = O(N^log2(8))

因此：

T(N) = O(N³)

### 5.2 Strassen 矩阵乘法

Strassen 算法将8次子矩阵乘法减少到7次。

递推关系：

T(N) = 7T(N/2) + O(N²)

根据主定理：

T(N) = O(N^log2(7))

其中：

log2(7) ≈ 2.807

因此：

T(N) = O(N^2.807)

原实验报告采用近似表达：

O(N^2.81)

## 6. 算法对比

| 对比项目 | 传统分治 | Strassen |
|---|---|---|
| 子矩阵乘法次数 | 8 | 7 |
| 额外矩阵运算 | 加减法 | 加减法 |
| 时间复杂度 | O(N³) | O(N^2.807) |

## 7. 实验结论

Strassen 算法通过增加矩阵加减运算，减少了一次子矩阵乘法，从而降低了矩阵乘法的渐近时间复杂度。

传统分治矩阵乘法的复杂度为 O(N³)，Strassen 算法的复杂度为 O(N^2.807)。

该算法体现了通过改变算法结构、减少高成本运算次数来提升计算效率的思想。
