# 01. Baseline: Naive Matrix Multiplication

## 1. 实验目的

建立串行矩阵乘法的性能基准，观察不同矩阵规模下的执行时间变化，为后续 Cache Blocking、SIMD 和 OpenMP 优化提供对照。

## 2. 实验原理

计算两个 N × N 的单精度浮点矩阵 A、B 的乘积：

C = A × B

其中：

C[i][j] = Σ A[i][k] × B[k][j]

计算完成后，求结果矩阵 C 的迹：

Trace = Σ C[i][i]

算法采用经典三重循环实现，时间复杂度为 O(N³)。

## 3. 实验环境与参数

- 算法：Naive Matrix Multiplication
- 数据类型：float
- 矩阵规模：512、1024、2048、4096、8192
- 随机种子：0.3
- 循环顺序：i-j-k
- 计时方式：gettimeofday()
- 计时范围：仅矩阵乘法计算阶段

## 5. 实验现象

随着矩阵规模增加，串行矩阵乘法的执行时间显著增长。

矩阵规模每扩大一倍，理论计算量约扩大八倍，但实际执行时间受到缓存、内存访问和运行环境等因素影响，并不严格按照八倍增长。

## 6. 实验结论

朴素串行矩阵乘法具有 O(N³) 的时间复杂度。

随着矩阵规模增大，计算开销迅速增加。经典 i-j-k 实现还存在矩阵 B 访问局部性较差的问题，为后续研究矩阵分块和数据访问优化提供了切入点。

## 7. 后续研究方向

- 研究不同循环顺序对数据访问局部性的影响。
- 引入 Cache Blocking，改善矩阵访问模式。
- 对比不同分块大小下的执行时间。
