# Part05 · AVX 4×16 微内核与寄存器优化

## 1. 研究目的

本章节分析 `Matrix_mul.c` 中的 `kern4x16()` 函数，研究 AVX SIMD 指令、寄存器分块、数据广播和中间结果复用机制。

该函数是整个矩阵乘法实现的核心计算内核，负责完成固定尺寸的4×16矩阵块乘加运算。

## 2. 微内核计算尺寸

源码定义：

```c
#define MR 4
#define NR 16
```

微内核计算：

C(4×16) = A(4×KC) × B(KC×16)

一次处理64个输出元素。

## 3. AVX 向量寄存器

源码使用 `__m256` 表示256位向量。

单精度 float 占32位，因此：

256 / 32 = 8

每个 `__m256` 可以同时保存8个 float。

64个输出元素需要：

64 / 8 = 8 个向量累加器。

## 4. 八个向量累加器

源码定义：

```c
__m256 c00, c01;
__m256 c10, c11;
__m256 c20, c21;
__m256 c30, c31;
```

每行使用两个向量寄存器：

- 第一个保存前8列。
- 第二个保存后8列。

四行共使用8个向量累加器。

这种设计使一个4×16输出块的部分结果能够持续保存在向量寄存器中。

## 5. B 数据加载与 A 数据广播

源码：

```c
__m256 b0 = _mm256_load_ps(bp);
__m256 b1 = _mm256_load_ps(bp + 8);
```

两次向量加载获得当前 K 位置的16个 B 元素。

随后：

```c
x = _mm256_broadcast_ss(a0 + k);
```

将 A 中一个标量广播到8个 SIMD 通道。

同一组 B 向量用于四行计算。

因此每个 K 位置：

- 加载2个 B 向量。
- 广播4个 A 标量。
- 完成8组向量乘法。
- 完成8组向量加法。

## 6. 单次 K 循环的计算量

输出块包含：

4 × 16 = 64 个元素。

每个元素执行一次乘法和一次加法。

因此：

64 × 2 = 128 FLOPs

当 KC=256：

128 × 256 = 32768 FLOPs

这是微内核的理论浮点运算量，不代表实际测得的计算吞吐量。

## 7. 寄存器累加

微内核开始时：

```c
__m256 c00 = _mm256_load_ps(c);
```

从 Ct 中读取已有部分结果。

K 循环中，结果持续在8个向量累加器中更新。

循环结束后，通过 `_mm256_store_ps` 将结果写回 Ct。

这种设计避免了每次 K 迭代都重新读取和写回 C 中间结果。

## 8. FMA 指令分析

当前源码使用：

```c
_mm256_mul_ps()
_mm256_add_ps()
```

分别表达向量乘法与向量加法。

源码没有显式使用 FMA Intrinsics。

最终机器码是否发生乘加融合，需要结合实际编译参数和反汇编结果确认。

后续重点检查：

```bash
objdump -d -M intel Matrix_mul
```

观察是否存在 `vfmadd` 等融合乘加指令。

## 9. 边界处理

程序使用 `kern_edge()` 处理不足4行的区域。

主计算函数优先使用4×16微内核，剩余行交由边界函数处理。

列方向不足16列则通过 Packing 补零。

对于 N=8192，行方向可以被 MC=64 整除，因此不会触发行方向边界处理。

## 10. 本章结论

当前微内核采用以下设计：

1. 使用256-bit AVX向量进行单精度浮点计算。
2. 使用8个向量累加器保存64个输出元素。
3. 每个 K 位置加载两个 B 向量。
4. 使用广播指令将 A 标量扩展到向量通道。
5. 同一组 B 向量复用于四行计算。
6. 在寄存器中持续累加，完成 KC 计算后再写回 Ct。

其核心思想是通过 SIMD 并行、寄存器分块和数据复用，提高计算资源利用效率并减少中间结果的内存访问。
