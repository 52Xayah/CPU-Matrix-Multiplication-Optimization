# Part06 · OpenMP 多线程调度与 NUMA 内存优化分析

## 1. 研究目的

本章节研究 `Matrix_mul.c` 中的 OpenMP 并行结构，分析任务调度、线程私有工作缓冲区和 NUMA 内存访问方式。

研究环境为双路 Intel Xeon E5-2620 服务器，具有12个物理核心、24个逻辑线程和两个 NUMA 节点。

## 2. OpenMP 并行结构

程序采用：

```c
#pragma omp parallel
{
    float *Bp, *Ct;

    // 分配线程私有缓冲区

    #pragma omp for schedule(dynamic, 1)
    for (long t = 0; t < ntiles; t++) {
        // 矩阵分块计算
    }
}
```

其中：

- `omp parallel` 创建并行执行区域。
- `omp for` 将矩阵分块任务分配给多个线程。
- `dynamic,1` 表示动态分配任务，每次分配一个循环迭代。

## 3. 线程私有工作缓冲区

每个线程独立申请 Bp 和 Ct。

| 缓冲区 | 容量 |
|---|---:|
| Bp | 128 KB |
| Ct | 32 KB |
| 合计 | 160 KB |

线程私有缓冲区可以避免多个线程同时写入同一工作缓冲区。

## 4. 动态任务调度

当 N=8192：

- 行方向任务数：128。
- 列方向任务数：64。
- 总任务数：8192。

每个任务处理一个64×128输出块。

当前使用：

`schedule(dynamic, 1)`

动态调度适用于任务计算量不均匀的情况。

但对于 N=8192，所有输出块尺寸相同，计算量基本一致，因此需要进一步比较 static、static,1、dynamic,1 和 guided 的运行表现。

不能仅凭调度方式推断实际性能。

## 5. 物理核心与逻辑线程

服务器具有12个物理核心和24个逻辑线程。

两个 Socket 分别拥有6个物理核心。

24个逻辑线程通过 Hyper-Threading 提供硬件线程能力，但并不等于24个独立物理核心。

后续建议比较：

1、2、4、6、8、12、16、24线程。

重点分析物理核心数量与逻辑线程数量对矩阵乘法性能的影响。

## 6. NUMA 内存架构

服务器包含两个 NUMA 节点。

每个节点具有：

- 6个物理核心。
- 12个逻辑 CPU。
- 约16 GB内存。
- 15 MB共享 L3 Cache。

NUMA 距离矩阵：

| 访问方向 | 距离 |
|---|---:|
| Node 0 → Node 0 | 10 |
| Node 0 → Node 1 | 21 |
| Node 1 → Node 0 | 21 |
| Node 1 → Node 1 | 10 |

远程访问具有更高的 NUMA 距离。

## 7. First-Touch 内存放置分析

A、B 矩阵在进入 OpenMP 并行区域之前，由主线程通过 `matrix_gen()` 串行初始化。

在 Linux 默认首次触碰内存策略下，页面可能集中分配在初始化线程所在的 NUMA 节点。

如果其他 Socket 的工作线程需要访问这些数据，就可能产生远程内存访问。

Bp 和 Ct 则在 OpenMP 并行区域中由各工作线程分别使用和写入。

因此，两类数据具有不同的潜在 NUMA 放置行为。

实际页面分布仍需通过进程 NUMA 统计确认。

## 8. 当前实现值得研究的方向

### 8.1 任务调度

比较 static、dynamic 和 guided 调度策略。

### 8.2 线程数量

比较6、12、24线程配置，分析超线程带来的实际收益。

### 8.3 CPU 亲和性

研究线程是否绑定到固定物理核心，以及不同 Socket 之间的线程分布。

### 8.4 NUMA 内存放置

研究 A、B 矩阵串行初始化是否造成内存节点分布不均。

### 8.5 工作缓冲区局部性

研究线程私有 Bp、Ct 是否能够保持本地 NUMA 访问。

## 9. 本章结论

当前实现采用 OpenMP 动态调度和线程私有工作缓冲区。

这种结构减少了工作缓冲区的共享写入冲突，但实际性能仍然受到线程数量、调度开销、CPU 亲和性和 NUMA 内存放置影响。

当前最值得进一步研究的是：

1. 规则矩阵规模下动态调度是否必要。
2. 12物理核心与24逻辑线程的性能差异。
3. A、B 串行初始化引起的潜在 NUMA 局部性问题。
4. 线程私有缓冲区的首次触碰和 CPU 绑定。

所有性能判断均需要后续实验验证。
